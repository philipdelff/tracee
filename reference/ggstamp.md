# Always stamp your plots with script name

This function is used to stamp ggplot type plots with datetime and
script name. User must provide the script name.

## Usage

``` r
ggstamp(
  plot,
  file,
  size,
  script,
  time,
  model,
  stamp.gg.style,
  stamp.format = NULL,
  stamp.funs = NULL
)
```

## Arguments

- plot:

  The plot to be stamped.

- file:

  An optional output filename to be included in the stamp.

- size:

  The size (list) for the plot, not the caption. Used to calculate the
  size of the caption.

- script:

  the script name. Date and time will be added automatically.

- time:

  The timestamp to be included.

- model:

  An optional model name or object to be included in the stamp.

- stamp.gg.style:

  A list of formatting options for the stamp text. For ggplot objects,
  valid elements include size, colour, hjust, vjust, and other
  parameters accepted by
  [`ggplot2::element_text()`](https://ggplot2.tidyverse.org/reference/element.html).
  For gtable objects, valid elements include col, fill, alpha, lty, lwd,
  lex, lineend, linejoin, linemitre, fontsize, cex, fontfamily,
  fontface, lineheight, and font. Default formatting is applied if not
  specified. Additionally, the element `position` controls where the
  stamp is placed: `"left"`, `"center"`, `"right"` (default) or a number
  between 0 (left) and 1 (right). `hjust` controls justification of the
  lines within the stamp and defaults to 0 (left-justified). Example:
  `stamp.gg.style=list(position="right",hjust=0)` places the stamp on
  the right with left-justified lines.

- stamp.format:

  A template for the stamp text using the placeholders `%script`,
  `%time`, `%model`, and `%file`, with `"\n"` for line breaks. Default
  is `"%file\n%script\n%model\n%time"`. See
  [`createStamp`](https://philipdelff.github.io/tracee/reference/createStamp.md).

- stamp.funs:

  Optional named list of functions (elements `script`, `time`, `model`,
  `file`) used to preprocess the values before they are inserted into
  `stamp.format`. See
  [`createStamp`](https://philipdelff.github.io/tracee/reference/createStamp.md).

## Value

A stamped plot object. If `size` is given, a `patchwork` object with the
stamp panel underneath the plot. Otherwise the plot with the stamp added
as caption. For gtable input, a gtable. If `plot` is a list, a list of
stamped plots.

## Details

The stamp text is generated by
[`createStamp`](https://philipdelff.github.io/tracee/reference/createStamp.md)
based on `stamp.format` and `stamp.funs`. If the plot already has a
caption, the stamp is added below it.

How the stamp is added depends on `size`:

- If `size` is given (always the case when called from
  [`ggwrite`](https://philipdelff.github.io/tracee/reference/ggwrite.md)),
  the stamp is drawn in a separate panel underneath the plot (combined
  using `patchwork`). The panel height is calculated from the number of
  stamp lines and the font size, and the plot height is reduced
  accordingly so the total size matches `size`. Placement of the stamp
  (`stamp.gg.style$position`) and justification of its lines
  (`stamp.gg.style$hjust`) are controlled independently.

- If `size` is not given, the stamp is added as the plot caption
  (`labs(caption=...)`) and styled using `theme(plot.caption=...)`. In
  this case, `hjust` controls both placement and justification.

For gtable objects (e.g. from
[`gridExtra::arrangeGrob`](https://rdrr.io/pkg/gridExtra/man/arrangeGrob.html)),
the stamp is added at the bottom using `arrangeGrob`.

ggplot 2.2.1 or newer is required.

## Examples

``` r
library(ggplot2)
data(ChickWeight)
p1 <- ggplot(ChickWeight,aes(Time,weight,group=Chick,colour=factor(Diet)))+geom_line()
script <- "note"
ggstamp(p1,script)

## Or use ggwrite which will call ggstamp when the `script` argument is provided.
ggwrite(p1,script=script,canvas="wide")
```
